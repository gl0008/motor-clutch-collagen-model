# Version 0 — Archived SLS prototypes

V0 contains the original exploratory models:

- `single_protrusion_1d`: one protrusion, stochastic clutches, and a nine-bond
  SLS collagen chain.
- `triangular_lattice_2d`: the earlier triangular bead lattice with SLS bonds.

These files are preserved because they document the starting hypothesis.  They
are not the recommended collagen-network model: V1 and later remove SLS and use
the professor's overdamped force balance.  Overdamped drag and SLS are distinct
constitutive ideas, but V1–V3 deliberately isolate the simpler elastic-network
plus drag mechanism before adding any material memory.
