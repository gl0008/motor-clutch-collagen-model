# G3 figure storyboard

Each figure must answer one question. The 99-fibre field is deliberately irregular; a fibre is highlighted only after an actual clutch attaches to it.

| Figure | One question | Required visual sequence | Valid conclusion |
|---|---|---|---|
| G3A | Can a growing tip first acquire a collagen contact and then transfer a controlled 5 nN load? | `0 bound` → shaft grows → red material-point spokes appear → highlighted fibre/crosslinks and true metrics respond | Attachment-to-load mechanics only; not migration or alignment prediction. |
| G3B | Does post-attachment adhesion feedback change a cell-intrinsic polarity decision? | Matched OFF/ON runs, with an explicit numerical separation criterion | The current short matched run has no separation. It is a negative diagnostic, not evidence for feedback. |
| G3C | Does releasing the rigid cell change its motion under the same solved reaction forces? | Fixed and released controls from same seed; cell trail and true displacement | Rigid-body action/reaction bookkeeping only. |
| G3S | Does a traction-only surface shell produce a broader collagen response than a single-cell module? | No attachment → multiple surface tips attach → collective response | 20 nN sensitivity test, not calibrated spheroid biology. |

Do not use a figure merely to display an attractive mesh. If a matched comparison does not separate, label it as a negative result or remove it from the main story.
