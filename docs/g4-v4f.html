What is evidence, and what is an assumption?

Direct mechanism support

Aligned collagen can guide MDA-MB-231 migration

Riching et al. found more persistent motion and constrained protrusions along aligned collagen. Carey et al. observed radially aligned fibers stabilize and enlarge nearby probing protrusions.

Indirect support

A successful protrusion can define a front

Aligned matrices reduce protrusion number and prolong the dominant protrusion, but the exact 120 s memory clock is not measured by these papers.

Mechanical correction

Two-way steric coupling

Collagen pore size and steric hindrance constrain MDA-MB-231 invasion. The equal-and-opposite reaction is required by the model mechanics; its inherited linear penalty stiffness remains provisional.

Model assumption

Current-position contact search

A bound site retains material identity. Only after complete failure does it search the deformed network around the current cell, every 5 s if no point is initially reachable. This is shorter than the effective ~18 s binding time and is checked over 0.5/2/5 s.

Numerical correction

Independent counter addresses

Seed, timestep, event type and clutch index are hashed separately. The 20-seed first-front directional resultant fell from 0.675 before this correction to 0.221 after it. This removes the old seed/site alias without adding a biological direction; matched E0–E3 cases still receive the same variate at the same stochastic address.

Provisional parameters

Probability gains and cone widths

\(\beta_a=\beta_m=2\), 45° front cone, 15° tract SD, and 120 s memory are declared sensitivity variables—not literature-fitted values.

    However — what v4F still cannot claim

    The corrected steric term prevents barrier-free passage in this 2D model, but it is not a calibrated 3D pore-crossing law. The cell remains a rigid circle and the memory clock and gains are provisional. There is no deformability, nuclear mechanics, proteolysis, plasticity or crosslink rupture.

    Current result: protrusion memory increases net displacement and persistence, but does not choose a reproducible world direction. Matrix cue alone and the cue-plus-memory combination do not pass the paired cue-direction endpoint.

    Numerical limits: the short audit preserves front-event order and exact pair-force balance, but does not pass displacement-direction agreement after halving the timestep, 180° cue rotation, or the <5% domain criterion. v4F is therefore an exploratory mechanism result—not a validated directional-migration model.
