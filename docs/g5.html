Generation 5 · tumour organoid ↔ collagen

From one cell to a whole organoid.

G5 scales the validated single-cell motor–clutch + bead–spring collagen core up to a multicellular tumour organoid: many motor–clutch cells held together by cell–cell adhesion, all coupled to one shared collagen network. It asks how the collective pull of many cells remodels the matrix and how the cells invade — grounded in Kolade/Gloria's 4MOSC1 organoid movies (~200 µm organoid, radial collagen, collective + occasional single-cell escape).

Newest G5 update · 3 September 2026, 2:14 PM ET · G5-0B

First isolate scale transfer, then change cell number

The G4→G5 audit found that drag, bead spacing, cell mobility, pull, cell radius, contact width and fibre density had changed alongside cell number. The new controls freeze the non-multicellular parameters to G4 so “multicellularity” is no longer mixed with silent recalibration.

What transfers

Per-sector motor–clutch traction is consistent between G4 and the larger G5 domain.

What does not amplify

Adding cells does not make each active sector pull harder; current collective behaviour comes from cell–cell mechanics.

What needs repair

Angular fibre coverage is extremely sparse. The next clean fix is geometric coverage, not wider hidden contact.

Interpretation boundary. These are lineage controls, not a new biological phenotype. They identify which G4 physics transfers and which G5 geometry must be corrected before collective invasion is attributed confidently.
G5D refinements · low adhesion v2 → high traction v3

Leader cells expose three regimes—but do not yet drag followers

G5D v2 marks a small outer fraction as EMT-like leaders with reduced cell–cell adhesion and maps stuck, collective-like and single-cell escape regimes. G5D v3 adds a separate traction multiplier to the same leaders. This is a cleaner test because adhesion and traction are no longer bundled.

Stuck

Adhesion 60, pull 6 nN: about 3 µm invasion; the organoid remains cohesive.

Collective strand

Adhesion 8, pull 45 nN, 12% leaders: about 18 µm invasion while cells remain connected.

Single-cell escape

Adhesion 1, pull 45 nN, 12% leaders: about 72 µm invasion with strong dispersal.

Evidence boundary. These are seed-23, two-hour personal simulation tests, not experimentally validated findings. High traction is now implemented, but the displayed factor-1.8 comparison does not improve follower advance. MMP secretion and measured leader phenotypes remain outside the model.
Updated G5C result · stiffness × strain-stiffening

Three MPa is the current alignment regime

The newer two-hour sweep changes the earlier “negligible stiffening” conclusion. At E=3 MPa, turning strain-stiffening on gives the largest recorded rise in near-field aster order and the tightest cohesion in this exploratory grid.

Too soft · E=1

Aster order falls from 0.76 to 0.67 without stiffening: cells disrupt rather than align the network.

Current best · E=3

Stiffening on raises aster order from 0.76 to 0.82 (Δ=+0.06) with cohesion 1.25.

Solver boundary · E≥10

Stiffening-on cases require a smaller time step before they can be interpreted physically.

Evidence boundary. This is a personal simulation sweep at adhesion 4 and pull 55 nN. It updates the internal model conclusion but does not yet validate 3 MPa against a Kolade-lab material measurement.
What each stage adds

Lineage controls 0A–0B, then staged build A → E

0A · scale transfer

One cell, G4-frozen parameters and matched fibre density test whether the single-cell physics survives the larger G5 domain.

0B · cell number only

Vary M=1–37 with fixed cells; per-active-sector traction remains approximately independent of M.

A · scaffold

N motor–clutch disks + a soft cell–cell adhesion potential pack into a cohesive, force-balanced organoid.

B · contract → radial

Fixed organoid; each surface cell reels nearby collagen inward. Near-field radial order rises.

C · stiffness × stiffening

The updated sweep finds the strongest aster rise at E=3 MPa with stiffening on; high-E stiffening runs need a smaller time step.

D · release → invade

Homogeneous cells translate under the reaction of their grip-reel traction; the first version mainly expands collectively.

D v2 · leaders → mode map

A small outer fraction receives 15% adhesion, exposing stuck, connected-strand and single-cell regimes across adhesion × pull.

D v3 · leader traction

An independent traction multiplier tests whether high-traction leaders can drag followers; the current two-hour result says not yet.

E · plasticity

Bell crosslink rupture + re-weld (stress-selective). Rewiring is real; a clean κ is still confounded by slow relaxation.

Near-field fix (A+B refinement)

Grippable fibres are gated to be boundary-connected and seeded as long radial tracts, so the pull reaches the mid-field.

What the model solves

Overdamped collagen balance
ζ ṙi = Fstretch + Fbend + Fcrosslink + Frepulsion + Factive

Same bead–spring engine as G2; repulsion now sums over every cell disk.

Cell–cell adhesion
Fcc(d): repel d<d₀, adhere d₀≤d<d₀+r

Soft adhesive disks (tissue surface tension); adhesion strength sets the invasion mode.

Leader adhesion + traction
kadhij = kadh min(si,sj);   Fleader = αpullF

Low adhesion and high traction are separate switches applied to the same selected outer cells.

Grip-reel reaction → invasion
γc ṙc = −Σ Fcell→ECM + Fcc

Reeling collagen inward pulls the cell toward the matrix = outward invasion.

Radial order
Sr = ⟨2(t̂·r̂)² − 1⟩

+1 radial (TACS-3-like aster), −1 tangential, 0 isotropic.

Bell crosslink plasticity
koff = koff0 exp(F/Fb)

Loaded welds rupture; fibres re-weld at their current crossings (topological remodelling).

Evidence boundary. Own-simulation output is personal testing, not a confirmed finding. G5-0A/0B expose a near-cell coverage problem; Stage-C now shows a positive E=3 MPa stiffening effect; Stage-D v2/v3 mode boundaries and leader tests are exploratory personal results; Stage-E plasticity rewires the network but a clean load–unload κ is confounded by slow large-scale relaxation (a full simulated hour recovers only ~19 %). Collagen is deliberately softened (3 MPa) as in G3/G4 so the pull visibly reorganises the near field. Not modelled: SLS viscoelasticity, proteolysis, 3D pores/nucleus, deformable cell cortex.
